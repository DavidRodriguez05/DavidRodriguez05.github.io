HabitFlow

Aplicación para crear hábitos y seguir tu progreso, con un apartado social para conectar con otras personas.

  • Crear hábitos y registrar tu progreso.
  • Estadísticas para ver cómo vas.
  • Logros y retos para mantener la motivación.
  • Apartado social: amistades y grupos con chat e invitaciones.
  • Una sola base de código en Flutter para Android, iOS y web.
  • Flutter
  • Dart
  • Java
  • Spring Boot
  • Spring Security
  • JWT
  • MySQL
  • Docker
Detalles técnicos
Arquitectura
App en Flutter que consume una API REST propia hecha en Java 21 con Spring Boot, organizada por áreas: autenticación, hábitos, estadísticas, retos, perfil y social.
Seguridad y datos
Autenticación con Spring Security y JWT, con tokens de refresco. Datos en MySQL con JPA y un esquema versionado con migraciones de Flyway. La API está documentada con OpenAPI (Swagger).
Despliegue
Docker Compose tanto para desarrollo como para producción, con la configuración sensible en variables de entorno y preparado para desplegarse en un VPS.
Mi papel
Proyecto individual: desarrollé la app y la API, tomé todas las decisiones técnicas y resolví los problemas que fueron surgiendo.
Lo que más me gusta
El apartado social de la aplicación.
Lo que aprendí
A diseñar y construir mi propia API y a consumirla desde una app multiplataforma.
Estado
Terminado. La app no está publicada en tiendas.

FlowManager

Gestor de tareas y proyectos en línea para organizarte tú solo o con tu equipo.

  • Proyectos compartidos: invitas a otras personas por email y cada miembro tiene sus permisos.
  • Tareas con filtros y archivos adjuntos.
  • Avisos por email de las tareas pendientes.
  • Panel de estadísticas con gráficos.
  • Asistente con IA conectado a la API de OpenAI.
  • PHP
  • MySQL
  • JavaScript
  • Tailwind CSS
  • React
Detalles técnicos
Arquitectura
PHP sin frameworks y MySQL, con un modelo de datos de seis tablas diseñado antes con un diagrama UML. Interfaz con Tailwind CSS y Flowbite, y validación de formularios en JavaScript.
Panel de estadísticas
Aplicación en React (Vite y Recharts) que consume endpoints PHP que devuelven JSON.
Cuentas y avisos
Contraseñas cifradas con password_hash, recuperación de contraseña por email y avisos automáticos con PHPMailer y una tarea programada (cron).
El mayor reto
Los permisos entre los miembros de un proyecto compartido.
Lo que aprendí
Consolidé PHP sin frameworks: sesiones, subida de archivos, envío de emails y endpoints JSON.
